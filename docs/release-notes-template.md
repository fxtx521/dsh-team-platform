# Release Notes Template / 发版说明模板

每次发版必须中英双语，按下面四段写细。不要只写一句话。

## 中文
### 新增
- 每条写清：做了什么、用户怎么用、和官方能力的关系（对齐/自造）
### 修复与加固
- 每条写清：原问题现象、根因、修法
### 验证
- 列出真实执行过的验证项与结果（命令/日志/数值），不写“应该没问题”
### 已知限制
- 明确尚不支持或需人工处理的地方（签名、网络、平台差异）

## English
Mirror the same four sections. Keep wording concrete and factual.

## 规则
1. 版本号必须递增且符合 semver，禁止回退。
2. 一次发版对应一个批次（5–8 项改动），不零发。
3. 发布前必须有独立验证记录（子代理或自测脚本），把证据写进 notes。
